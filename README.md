# tapcard — сайт-визитка для NFC-карт

Одностраничный лендинг под QR-код на физической карте. Один файл `index.html`, без сборки и зависимостей: можно открыть локально или залить на любой хостинг.

## Публичная ссылка

**https://vladsuhorucov00-glitch.github.io/tapcard/**

Сайт размещён на GitHub Pages, репозиторий: https://github.com/vladsuhorucov00-glitch/tapcard

Файлы QR-кода в папке проекта:

- `qr-tapcard-1200.png` — для печати и вёрстки макета
- `qr-tapcard.svg` — вектор, масштабируется без потери качества

Чтобы обновить сайт, замените `index.html` в репозитории — ссылка и QR-код останутся прежними.

## Как продаём

Сайт — визитка, а не магазин. Продажи только офлайн: нет формы заявки, онлайн-оплаты, доставки и цен. Вместо этого — прямые контакты (звонок, Telegram, WhatsApp, e-mail) и приглашение на личную встречу, где показываем образцы, подбираем комплект и настраиваем карты при клиенте.

Поэтому на сайте нет ни одного поля ввода: данные посетителей не собираются.

## Как открыть

Двойной клик по `index.html` — откроется в браузере. Для проверки шрифтов и анимаций лучше запустить локальный сервер (не обязательно).

## Что обязательно заменить

| Что | Где менять |
|---|---|
| Название бренда `tapcard` | логотип в шапке и подвале, `<title>`, `og:title`, `CONFIG.brand` |
| Телефон, Telegram, WhatsApp, e-mail | блок `CONFIG` в конце файла — контакты подставятся во все ссылки автоматически |
| Состав комплектов | раздел `#pricing` (сейчас «Старт» / «Бизнес» / «Сеть», цена — по запросу) |
| Отзывы клиентов | раздел `#reviews` — сейчас это демонстрационные тексты, замените на реальные или удалите блок |
| Сроки изготовления, условия встречи | тексты в шапке, FAQ и комплектах |
| Политика конфиденциальности | `<dialog id="privacyDialog">` |

`CONFIG` находится в самом низу файла:

```js
const CONFIG = {
  brand: 'tapcard',
  phoneDisplay: '+7 (900) 000-00-00',
  phoneRaw: '7900000000',   // только цифры
  telegram: 'tapcard',      // без @
  email: 'hello@tapcard.ru'
};
```

## Контакты вместо формы

Раньше здесь была форма заявки — она удалена вместе с обработчиком. Все кнопки на сайте ведут напрямую:

- «Позвонить» — `tel:` из `CONFIG.phoneRaw`
- Telegram — `https://t.me/<CONFIG.telegram>`
- WhatsApp — `https://wa.me/<CONFIG.phoneRaw>`
- Почта — `mailto:<CONFIG.email>`

Чтобы контакты поменялись везде, достаточно отредактировать `CONFIG` — остальные ссылки обновятся скриптом при загрузке страницы.

## Публикация и QR

1. Залейте `index.html` на хостинг: Netlify Drop, GitHub Pages, Vercel или обычный shared-хостинг.
2. Проверьте адрес на телефоне: скорость загрузки, кнопки звонка и мессенджеров.
3. Сгенерируйте QR-код на финальный URL и разместите его на обороте карты (готовые файлы — `qr-tapcard-1200.png` и `qr-tapcard.svg`).
4. Проверьте связку: QR → сайт, NFC-метка → карточка организации в Яндекс Картах / 2ГИС.

Совет: используйте короткий домен и постоянный URL — если адрес изменится, старые QR-коды и NFC-метки перестанут работать.

## Технические детали

- Адаптив: проверены ширины 390, 768 и 1440 px, горизонтального скролла нет.
- Доступность: Lighthouse Accessibility / Best Practices / SEO — 100 / 100 / 100.
- На сайте нет форм и полей ввода — собирать персональные данные нечего.
- Анимации отключаются при `prefers-reduced-motion`.
- Шрифт Manrope подключён с Google Fonts. Для полностью офлайн-версии удалите три `<link>` в `<head>` — останется системный шрифт.
- Все иконки и иллюстрация телефона — inline SVG/CSS, внешних картинок нет.
- Демо в первом экране: нажатие на NFC-карту запускает анимацию отзыва (работает и на телефоне).
